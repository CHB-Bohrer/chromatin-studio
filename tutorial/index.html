Start with the workbench

Chromatin Studio connects a model builder, a spatial simulation, and measurements from the current run. Each chromatin bead is a stretch of DNA, and its size is a model setting. This walkthrough uses one size throughout: two hundred base pairs per bead, about one nucleosome and its linker. The example is Manuscript hypotheses at eighty kilobases: four hundred beads of two hundred base pairs each. The default model and the small presets all use this size. Only the twenty-megabase presets keep coarse ten-kilobase beads, each standing for many nucleosomes, and they are not shown here. The center shows the applied model. Builder changes belong to the draft until they are applied. Begin by checking the bead size, the run status, and the physical-clock label.

Choose a focused experiment

The Manuscript hypotheses example is the main model for this walkthrough. Each of its four hundred beads is two hundred base pairs, a coarse nucleosome unit that can be occupied or vacant. Nucleosome occupancy and individual transcripts are enabled. The preset includes transcription factors, coactivators, and illustrative active and repressive marks. These are starting hypotheses, not fitted biology. Expand builder gives the settings room. Ordinary edits stay in the draft until Apply and restart. How it works is a separate learning sandbox: its sliders explain equations without changing your run.

Save your work, pick an engine, and grow a model

Three everyday tools sit in the top bar. Import loads a model file into the draft, and Export saves the draft as a model file, so an experiment can be shared or rebuilt exactly. Save run downloads the applied model together with its current state and the history the server recorded. That is one snapshot plus measurements, not a full trajectory. Beside the Experiment menu, Engine chooses how the run is integrated. Brownian reference is the built-in engine used throughout this tutorial. Polychrom with OpenMM is an integration adapter: forces and reactions still run on the CPU. The Model tab lists which engines are installed here. Model size is no longer capped. In this example the chain was raised to five thousand beads, one megabase. The model still runs, but the notes below the observables now include a Large model warning, because the live engine and the 3D view were sized for about four thousand beads and six thousand particles. Open these model notes whenever you change a model.

Set the confining domain

The polymer already has confinement. System now makes the wall explicit: outside the chosen radius, a harmonic force pushes particles inward. Increasing wall stiffness reduces penetration; zero switches the force off. This is a soft wall, so particles are not clipped back to the boundary. The diagnostics report excursions for mechanical particles and released RNA. For a small locus, this sphere is a modeled domain, not automatically an entire nucleus. Compare radius and wall strength, because packing can change contacts and transcription even when every biochemical parameter stays the same.

Watch binding along the chromosome

For a clearer view of binding, switch to a smaller example. In the Experiment menu it is called Live nucleosome access, twenty-five point six kilobases. That simply means a twenty-five point six kilobase stretch of chromatin: one hundred twenty-eight beads, still two hundred base pairs each, set up so that nucleosomes visibly control which sites proteins can reach. Open the one-dimensional genome and choose Live binding. Genes, nucleosome occupancy and directly bound proteins share one genomic axis. Navigate to a gene, then use Binding detail to see individual sites. Each molecule marker comes from a real chromatin bond; proximity alone is not binding. Run to watch bindings change, then pause and select a site. The table gives two rates for each protein. The association hazard is how often a nearby molecule binds, per unit of time. The release hazard is how often a bound molecule lets go; one over the release hazard is the average time it stays bound. Times remain reduced until an empirical physical mapping is attached. All tracks restores the wider view of marks, loops, polymerases and protein preferences.

Create gaps and recruit remodelers

Stay in the twenty-five point six kilobase nucleosome-access example. In Chromatin, define an initially vacant interval to create a nucleosome-free region. This sets the starting state; reassembly can fill the gap later. In Proteins, each species has separate multipliers for occupied and vacant sites: one scales how often it binds, the other how quickly it lets go. Opening a site can favor one species and disfavor another, especially when eviction also removes a mark. Add chromatin remodeler creates an editable species and enables occupancy in the draft. Its eviction, reassembly and sliding rates act when it is attached to chromatin or recruited through a configured transcription factor. Eviction clears marks. Reassembly starts unmarked. Sliding moves occupancy and its marks into an adjacent vacant bead, conserving nucleosome number. Inspect Recorded binding and remodeling events to follow what actually occurred. These are recent recorded events, not a complete microscopic history. Apply changes only when ready to start a new run.

Add the whole nucleus and tethering elements

Return to the eighty-kilobase example, open Bodies and add Whole nucleus. The modeled region still sits inside its own confinement sphere, while a much larger soft envelope represents the nuclear periphery. The region is a small part of the nucleus, so one side of it meets the envelope. By default that is the side away from the nucleolus, which faces the nuclear interior; you can move the envelope. Then add tethering elements: genomic intervals, such as lamina-associated domains, whose beads can attach to the envelope or to a landmark surface. Each bead within the capture distance attaches with its own hazard and, once attached, feels a spring to a fixed anchor. Attachment can require a mark and an occupied nucleosome, and vacant sites can release faster. In 3D, tick Whole nucleus to frame the envelope, and look for amber tether links. In 1D genome, the Tethers row shows attached beads, and the Nucleosomes row marks every vacant site. Tethers are phenomenological anchors, not lamina proteins.

Define many proteins and their roles

The rest of the walkthrough stays in the eighty-kilobase example. The Proteins editor defines each species independently. Expand builder gives these settings room. Set abundance, free diffusion, binding valence, mark preferences, and occupied-versus-vacant capture and release factors. A species can also write or erase a mark, or remodel nucleosomes. An IDR representation expands a molecule into a flexible chain of domain beads with binding stickers. This supports higher-order assemblies, but it is not an amino-acid-resolved protein model. Choose roles and interactions as explicit hypotheses; a biological name is not a calibrated parameter set.

Inspect binding in its context

The interaction view shows the current molecular network. Distinguish molecules with their own chromatin bond from those tethered indirectly through another protein. Protein pairs can bind while both are free, while one is directly chromatin-bound, or while both are bound. These are bond-mode links, the default. A pair can instead use attraction mode, which forms no bonds; the phase separation chapter covers it. The affinity calculator explores an ideal diffusion-limited association estimate after physical scales are supplied. Its nominal dissociation rate follows the requested Kd under independent, well-mixed assumptions. It does not turn the simulator's local encounter hazard into a measured molar association rate.

Connect accessibility, marks and stiffness

Nucleosome occupancy is an explicit local state when this option is enabled. Eviction can expose a TF site, clears marks at that site, and changes the configured local persistence multiplier. Bound writers and recruited coactivators can alter marks; spreading follows three-dimensional chromatin contacts. Mark-dependent chromatin attraction is a separate interaction from a protein's mark preference. The learning example lets you compare occupied and vacant capture hazards and persistence values. Those numerical relationships explain a hypothesis; the illustration is not an equilibrium polymer calculation.

Follow an enhancer to its target gene

Regulation now shows the causal pathway for each gene. A transcription factor binds its configured region, and a coactivator is recruited through an actual protein bond. Enhancer contact can add to the target promoter's activation and initiation rates. The rate breakdown separates the baseline, recruitment, local mark gate and optional body response. Nucleosome occupancy changes transcription factor access; recruited enzymes can alter marks and accessibility. Basal activation can remain possible without recruitment. Losing contact removes its gain, but does not instantly turn an active promoter off or erase its chromatin memory.

Watch polymerases produce individual RNA

Transcription is stochastic. The engine now follows promoter switches within each reaction interval, and draws initiations only during the time actually spent active. Each new polymerase moves for the time remaining after its birth. Inspect its identity, position and growing RNA length in Elongation. Nucleosomes can slow movement; configured pauses have stochastic waiting times. Completed transcripts become diffusing points that can be processed or degraded. Nascent RNA can remain after a promoter switches off, so a nascent-positive gene is not the same as an active promoter.

Separate loops, assemblies and nuclear bodies

Cohesin, protein assemblies and nuclear bodies organize space through different rules. Cohesin changes contacts through moving loop anchors. Protein bonds form higher-order assemblies. Speckles and the nucleolus are currently imposed fields, not self-generated condensates. In Genes, optional body responses can promote or suppress activation and initiation. A multiplier of one is neutral; the effect fades with promoter distance. These prescribed responses do not bypass the mark gate. Keep them separate from mechanical body attraction and from the speckle's effect on released RNA processing.

Grow droplets from attraction alone

Phase separation at eighty kilobases shows a second way proteins can interact. Choose it from the Experiment menu. Around the same four hundred bead chain it places six hundred scaffold proteins and one hundred fifty clients, each a single bead. Open Interactions. These pairs use attraction mode: instead of forming bonds, two nearby proteins feel a shallow energy well. Here, Link strength is the well depth at contact, one and a half kT between scaffolds and nine tenths between client and scaffold, and Encounter radius is where the well ends. The association and dissociation rates are not used in this mode. This model needs hundreds of thousands of steps, more than the live engine reaches in a session, so the next states were advanced with the native engine and then opened in the workbench for display. At the preset's six hundred scaffolds, clusters of up to about forty molecules formed and dissolved again over four hundred thousand steps. Next, raise the scaffold count to one thousand and apply. Now dense droplets of about two hundred fifty molecules appear within about fifty thousand steps and persist, while about a fifth of their members are replaced every twenty-five thousand steps. Several droplets formed and had not merged by three hundred thousand steps. That contrast is what to look for: a dense phase that coexists with a dilute one, appears only above a threshold concentration, and keeps exchanging molecules. These are single runs, and an earlier GPU check did form one droplet at six hundred scaffolds, so the preset sits close to the threshold. Largest assembly stays at one, because it counts bonds. The well depth is not a measured affinity.

Give the polymer a defensible physical clock

Calibrate can import a condition-specific Hansen reference. Then supply a matched, equilibrated simulation and independent length evidence. Importing data does not complete calibration. Match the observable, dimension, drift treatment and fitting window. Next, load the synthetic example to practice fitting. Inspect its overlay, residuals and slopes; it cannot be applied as experimental evidence. A shared polymer clock converts reduced durations and rates consistently, but does not independently fit protein diffusion, binding residence times, elongation or Kd. Compatible empirical mappings retain their sources and baseline model fingerprint.

Ask what the model actually reproduces

The benchmark panel separates implementation checks, an ideal Rouse reference, and published-figure replication. Solid curves show sampled reference trajectories; dashed curves show analytical predictions. The saved suite tests free diffusion, internal-chain motion, center-of-mass diffusion and illustrative static-loop suppression. These fixtures exercise the actual Brownian integrator but bypass the production forces and coupled reaction system. Passing them is evidence about implementation. It is not a reproduction of every figure in the cited paper, and it supplies no experimental clock.

Separate competition and shared environments

Studies provides a simpler model for the manuscript's cis and trans comparison. Each simulated cell has four promoters: two genes on each of two homologs. All four share cell-wide variation. Genes on the same homolog may compete or experience a common fluctuating environment. The reference has no spatial polymer. Start with independent promoters, then add competition or shared environments separately. The experiment runs in isolation, leaving your current simulation untouched. Its purpose is to test whether a mechanism can produce a pattern, before asking whether the full spatial model or the experimental data support it.

Read correlations without confusing controls

After the study finishes, compare cis and trans correlations and their difference. The interval reflects sampling uncertainty, not proof of causality. Switch between latent nascent activity, detected activity and promoter state; these observables answer different questions. The spatial pilot instead measures two genes on one chain across independent replicas. Its independent-replica null is not a trans-allele control. Download the plan and results to retain parameters, seeds and limitations. Reproducing the manuscript quantitatively still requires the underlying data, matched observation models, calibrated units and substantially longer converged experiments.

Check what the component tests actually showed

Evidence shows the component tests that were actually run. Each study switches on one mechanism and compares the engine with its own rule, a closed-form result, or a published measurement. Those three levels are counted separately. The page only reads saved reports, so it runs nothing and leaves your simulation untouched. Select a study to see its figures. In the nucleosome kinetics study, based on Donovan and colleagues, blocking the site alone makes Reb1 and Cbf1 bind far too weakly. Matching their titrations requires slower release from the nucleosome. Hover for values, or open the table. Every check shows its accepted window, and experimental checks say whether they are input-matched, tuned, or a prediction. A pass under the provisional unit mapping is not a calibration. For a plain-language account of every mechanism and the check behind it, read the software paper in the docs folder.

Export a reproducible cluster experiment

When the model is ready, open Cluster job. Choose the device platform, independent replicas, output intervals and resource requests, then preview the scripts before exporting. The bundle carries the draft configuration, code, seeds and validation workflow for a fresh run. It does not resume the current live state. GPU use in an exported job is partial: forces, reactions and RNA run on the CPU, and only the integrator runs on the device, so speedup is not established. The faster native GPU engine, which runs bare polymers and the phase separation model, is used from Python and is not yet part of the exported job. Keep the model, inputs and results together, and use controlled comparisons to turn a visual hypothesis into testable evidence.
