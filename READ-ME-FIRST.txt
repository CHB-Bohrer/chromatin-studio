CHROMATIN STUDIO: UPLOAD USING THE GITHUB WEBSITE

Repository: https://github.com/CHB-Bohrer/chromatin-studio

The four numbered folders each hold fewer than 100 source files:
  01-application:               84 files
  02-tests-and-reference-data:  86 files
  03-tutorial-player:           72 files
  04-tutorial-narration:        34 files

1. Extract this ZIP. Open the extracted folder in Finder.
2. In Finder, press Command + Shift + Period to reveal hidden files.
   This is needed to include .github and .gitignore in the first batch.
3. Open the GitHub repository at its TOP LEVEL (the Code tab).
   Choose "uploading an existing file", or Add file > Upload files.
4. Open 01-application in Finder, select ALL CONTENTS inside it, and drag
   those files and folders into the GitHub upload area. Commit changes.
   Do NOT drag the numbered 01-application folder itself.
5. Return to the repository TOP LEVEL and repeat with the contents of
   02-tests-and-reference-data, then 03-tutorial-player, then
   04-tutorial-narration. Commit each batch before starting the next one.
   For both tutorial batches, drag the tutorial folder found INSIDE
   the numbered batch folder. GitHub will merge its new files into the
   existing tutorial directory. Do not navigate into tutorial on GitHub
   before uploading these batches, or you would nest it twice.

Do NOT upload the ZIP, this instruction file, the manifest, or the
numbered wrapper folders. The numbered folders are only upload helpers.
Keep the source files' subfolders intact.

If you already committed some files, these batches contain identical
release files and can complete the upload. Review any replacement shown
by GitHub if you have since edited a file online.

The complete manuscript is excluded. All 276 source files are unchanged
from the prepared v0.10.0 public release. Every individual file is below
25 MiB. The batch counts above exclude these local upload instructions
and the local integrity manifest, which are not repository files.
