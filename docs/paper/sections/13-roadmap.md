# Roadmap

The next concrete steps, in the order the project status proposes them:

1. **Confirm the interpolated fits.** Run HP1α at a hazard near 0.8 and Sox2 at a hazard near 0.235.
2. **Test a missing mechanism.** Add competitor-facilitated dissociation as an optional rule and see if it fixes the HP1α competition miss.
3. **Run the cohesin–Fbn2 study** overnight.
4. **Accept or revise the polymer calibration** (Section 11).
5. **Calibrate biological mechanisms one at a time**: protein mobility and residence, transcription, marks, before combining them.
6. **GPU and cluster performance**: move the chemistry bottlenecks to the device, with parity checks.
7. **Larger nucleosome-resolution systems**, with demonstrated memory and speed scaling.
8. **New biology when a question needs it**: emergent bodies, RNA chains, polymerase traffic, mechanochemical remodeling.

Engineering items also remain: exact restart checkpoints, packaging the web assets so the app installs without a source checkout, and choosing a software licence.
